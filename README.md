# Synectra Backend

Backend REST API for the Synectra project, built with NestJS and Supabase (PostgreSQL).

## 🚀 Fitur yang Sudah Dibuat (Implemented Features)

- **Authentication**: JWT & Google OAuth 2.0 integration.
- **User & Client Management**: Pengelolaan data klien, bank accounts, social media, dan kontak.
- **Portfolio & Banners**: Modul manajemen konten portofolio dan banner.
- **Orders & Payments**: Layanan manajemen pesanan, progress tracking, dan pembayaran.
- **Mail Service**: Pengiriman notifikasi via email terintegrasi.
- **API Documentation**: Swagger OpenAPI terintegrasi.

> **Note:** Untuk panduan arsitektur, aturan Clean Code, struktur MC (Model-Controller), dan detail implementasi, silakan merujuk ke file [`AGENTS.md`](./AGENTS.md).
